# 安装与实机验收

当前未进行实机测试；两个包均为实验开发包。

1. 从 `dist/` 选取与游戏分支对应的 zip，把 `.mod` 文件和同名文件夹放到用户的 `Victoria 3/mod/`。
2. 在启动器新建测试播放集，仅启用此模组。使用可丢弃的新存档，以玩家国家进入游戏。
3. 日志中应出现“雇佣兵事务（开发预览）”。确认中文和英文显示、状态数字、模拟余额、周费和倒计时没有缺失文本。
4. 正式雇佣按钮应不可点击。记录真实国库、正规军、兵营和人口。
5. 启动 Lv.2、5 营模拟：余额从 1,000,000 降为 988,000；周费 3,000。四次周更新集结结束，此时没有新增服役账单。
6. 第一轮服役更新后余额 985,000，剩余服役周数 51。52 次服役更新后余额 832,000，进入撤离。
7. 下一次更新关闭合同；再经过八次更新才能签新合同。
8. 另开一次模拟，服役时清空模拟余额。欠薪第 1/2/4 次观察警告，第 6 次进入撤离；欠款 18,000，失信一次。
9. 撤离、休整后，旧债应仍阻止新合同。充值 100,000 并偿债后余额 82,000，失信记录仍保留。
10. 最后四周续约一次，应增加 52 周；同一天再次续约不可用。提前解约仅扣一次四周赔偿，撤离后不再收费。
11. 在集结、服役、欠薪、撤离和休整各阶段保存读取，检查状态未重置、没有额外扣费。
12. 与初始记录比较，真实国库只应发生原版正常预算变化，模组不增加真实费用；部队、兵营、人口没有由本模组创建或删除。

还需检查：日志是否重复生成、多人不同玩家隔离、切换国家、革命继承、两个版本下加载错误与日志性能。不要以 Python 测试通过代替上述验收。
